# 影匣 · 本地影片库

单文件、零依赖的本地影视元数据管理页面。数据只保存在**使用者自己的浏览器**里，上传本仓库不会上传任何影片数据。

## 这是什么

- 管理影片 / 剧集 / 演员的元数据：片名、发行日期、类型、国家、评分评级、评价、封面、关联演员、观看日期等。
- **不存储影片本体**，可关联本地视频文件的元数据（文件名、容量）用于页内播放。
- 侧栏有观看热力图；支持按状态、类型、国家组合筛选。
- 数据保存在浏览器 localStorage 中；不同设备、不同浏览器之间**不会自动同步**。

## 怎么用（给自己看）

1. 打开网站链接（或本地双击 `index.html`）。
2. 点「+ 影片」「+ 剧集」「+ 演员」录入。
3. 定期点左侧栏「数据」→「导出备份」：可导出**含全部数据的 HTML 备份**（双击即可在另一台电脑恢复）或 JSON 文件。
4. 换设备 / 换浏览器 / 清理浏览器数据前，务必先导出备份，否则数据会丢失。

## 上传到 GitHub Pages（小白步骤）

1. **注册账号**：打开 github.com → Sign up → 用邮箱注册 → 到邮箱点验证链接。
2. **新建仓库**：右上角 `+` → New repository；
   - Repository name 填**英文小写**，例如 `yingxia`（这个名称会出现在最终网址里）；
   - 选 Public（推荐，免费）；
   - **不要**勾选"Add a README file"（本包已附 README）；
   - 点 Create repository。
3. **上传文件**：在仓库页面点 `Add file` → `Upload files` → 把本文件夹里的 `index.html` 和 `README.md` 拖进去 → 点 `Commit changes`。
4. **开启网页**：仓库页面 → `Settings` → 左侧 `Pages` → Build and deployment：
   - Source 选 `Deploy from a branch`；
   - Branch 选 `main`，目录选 `/(root)`；
   - 点 Save。
5. **拿到链接**：等待 1–2 分钟后刷新，页面顶部出现 `https://您的用户名.github.io/仓库名/`，即为影匣网址。
6. **以后更新**：重复第 3 步，把新版 `index.html` 再传一次（同名文件覆盖），等待几十秒刷新即可，链接不变。

## 注意事项

- 文件名务必保持 `index.html`，这样打开仓库主页网址就是影匣，不必带一长串中文文件名。
- 网页本身是**公开可访问**的（任何拿到链接的人都能打开），但每个访问者看到的只是**自己浏览器里的数据**，彼此不可见、互不影响。
- **不要**把含真实数据的截图一起上传仓库。
- 若希望多台设备自动同步数据，需要另外接入云端数据库，当前版本不具备此能力。
- 浏览器需支持现代 HTML5（Chrome / Edge / Safari 均可）。
