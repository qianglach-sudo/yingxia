# 影匣 · 本地影片库

单文件、零依赖的本地影视元数据管理页面。数据只保存在**使用者自己的浏览器**里，上传本仓库不会上传任何影片数据。

## 这是什么

- 管理影片 / 剧集 / 演员的元数据：片名、发行日期、类型、国家、评分评级、评价、封面、关联演员、观看日期等。
- **不存储影片本体**，可关联本地视频文件的元数据（文件名、容量）用于页内播放。
- 侧栏有观看热力图；支持按状态、类型、国家组合筛选。
- 数据保存在浏览器 localStorage 中；不同设备、不同浏览器之间**不会自动同步**。

## 怎么用（给自己看）

1. 打开网站链接（或本地双击 `index.html`）。
2. 点「+ 影片」「+ 剧集」「+ 演员」录入。
3. 定期点左侧栏「数据」→「导出备份」：可导出**含全部数据的 HTML 备份**（双击即可在另一台电脑恢复）或 JSON 文件。
4. 换设备 / 换浏览器 / 清理浏览器数据前，务必先导出备份，否则数据会丢失。
